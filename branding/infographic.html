One GPU, two jobs

Your graphics card is drawing the game and hosting the model.

RimWorld renders the colony while a local LLM answers in the background — and both live in the same pool of VRAM. When the model no longer fits, it spills into system RAM and inference slows by an order of magnitude. This tool makes that budget visible, in-game, before it bites.

What it shows

Live telemetry

VRAM, temperature, utilization, power draw, clocks and fan — read directly from NVIDIA's NVML library. No process spawning; Workshop-safe.

VRAM breakdown

The measured total, split into System / desktop, RimWorld's own textures, and (optionally) your local model — so you see exactly where memory went.

On-load advisory

A heads-up when a colony loads and you're near the ceiling — with practical suggestions before a raid or late-game turns into a stutter.

Overlay + dashboard

A draggable on-screen HUD you cycle Off → Basic → LM Studio → Developer, plus a full stats window from the toolbar.

Optional LM Studio

Point it at an OpenAI-compatible endpoint and it reads the loaded model, estimating its footprint at ~0.65 GB per billion params (Q4-class).

Remote-aware

Running the model on another machine? The remote host is detected and its memory is never charged against your local GPU.

Why it helps the local-AI community

  • shared

    RimWorld now hosts local LLMs — RimTalk, the RimSynapse suite, and more. The game and the model compete for one pool of VRAM, and most players never see that number.

  • the wall

    Running out of VRAM is the #1 failure. The model spills to system RAM and tokens-per-second collapse — the classic "it worked, then got slow" that's really a memory problem.

  • right-size

    Real numbers, not guesswork. Seeing the split lets you right-size the model and context window on purpose instead of trial-and-error until something breaks.

  • any stack

    Not tied to one mod. It works with any local LLM served over an OpenAI-compatible endpoint, and needs no companion — a general utility for the on-device-AI crowd who happen to also play RimWorld.
