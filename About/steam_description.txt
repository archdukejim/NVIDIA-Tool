GPU Monitor for NVIDIA GPUs — see your VRAM, temperature, and hardware live inside RimWorld. A standalone diagnostic tool, especially handy when you run a local LLM (LM Studio, RimTalk, RimSynapse) alongside the game.

[b]Version:[/b] v1.0.0 (Target: RimWorld 1.6)

[h1]GPU Monitor for NVIDIA GPUs[/h1]
[b][url=https://github.com/archdukejim/NVIDIA-Tool/wiki]Official Wiki and Documentation[/url][/b]

[b]A standalone, in-game GPU toolkit for RimWorld.[/b] It renders your NVIDIA GPU's VRAM, temperature, utilization, power, clocks, and fan directly inside RimWorld's UI — no external programs or overlays needed.

This is a general-purpose tool with [b]no dependency on any other mod[/b] (only Harmony). It is especially useful if you run a local language model alongside the game — the colony and the model share one pool of VRAM, and this shows you exactly how that budget is spent.

[h2]What it does[/h2]
[list]
[*] [b]Live GPU monitoring:[/b] Reads your GPU via NVIDIA's NVML library in real time — VRAM, temperature, utilization, power draw, clocks, and fan. No process spawning; direct native calls, fully Workshop-safe.
[*] [b]VRAM breakdown:[/b] Splits the measured used-VRAM into System / desktop, RimWorld itself, and (optionally) a local LM Studio model, so you see where your GPU memory actually went.
[*] [b]VRAM advisory:[/b] A proactive on-load heads-up when you are approaching your card's limit, with practical suggestions.
[*] [b]In-game overlay HUD:[/b] A draggable, toggleable overlay. Cycle Off → Basic (VRAM) → LM Studio → Developer (full hardware).
[*] [b]Dashboard window:[/b] A full stats view opened from the toolbar button.
[/list]

[h2]Optional: Local LLM (LM Studio) awareness[/h2]
[list]
[*] Off by default. Enable it in mod settings and point it at your LM Studio endpoint (default 127.0.0.1:1234).
[*] When enabled and reachable, it reads the loaded model directly from LM Studio's own HTTP API and estimates its VRAM footprint from the parameter count.
[*] A remote LM Studio host is detected and never counted against your local VRAM.
[*] It talks to LM Studio directly — it does NOT require RimTalk, RimSynapse, or any other mod.
[/list]

[h2]Compatibility[/h2]
[list]
[*] Royalty / Ideology / Biotech / Anomaly DLC: Compatible.
[*] Safe to add or remove from any save — zero save-file footprint (no GameComponent).
[*] Runs happily alongside GPU/VRAM features in other mods; when another mod ships its own on-load VRAM advisory, this tool suppresses the duplicate popup and keeps its overlay and dashboard.
[/list]

[h2]Requirements[/h2]
[list]
[*] Harmony (loaded before this mod).
[*] An NVIDIA GPU with a current driver. On machines without an NVIDIA driver the tool stays quiet and simply reports that GPU advisories are unavailable.
[/list]

[h2]Changelog (v1.0.0) - Standalone[/h2]
[list]
[*] NEW - Rebranded to a standalone, general-purpose GPU tool. No longer requires RimSynapse Core (or any other mod) — only Harmony.
[*] NEW - Optional LM Studio awareness that talks to your endpoint directly: reads the loaded model and estimates its VRAM. Off by default. Works with RimTalk, the RimSynapse suite, or any local-LLM setup. On Windows a "localhost" endpoint auto-retries over IPv4 (LM Studio binds IPv4 only).
[*] Changed - Overlay modes are now Off, Basic (VRAM), LM Studio, and Developer (full hardware).
[*] Changed - Suppresses a duplicate on-load VRAM popup when another mod already ships one.
[*] Removed - The RimSynapse-specific LLM dashboard (request queue, throttle, token metrics, registered mods, context) that depended on Core.
[/list]
